## 💎 Featured Projects

### 🌐 Nexora — Distributed Professional Social Network *(Flagship Project)*
Enterprise-grade, event-driven distributed social network architecture engineered to handle high-throughput interactions with polyglot persistence, real-time STOMP messaging, and cloud-native resilience.

- ⚡ **Microservices & Java 21 Loom**: Decoupled architecture across 6 microservices (API Gateway, Discovery Server, User, Posts, Connection, Notification, Chat) leveraging Java 21 Virtual Threads for high-concurrency non-blocking I/O.
- 🗄️ **Polyglot Persistence**: PostgreSQL for ACID transactional entities, **Neo4j AuraDB** for $O(1)$/$O(k)$ graph traversals (friend recommendations & 1st-degree circles), and **Redis** for rate limiting & single active session enforcement.
- 📨 **Event-Driven Fan-Out**: **Apache Kafka** event streaming for asynchronous post fan-out, real-time live notification badges, and analytics.
- 🚀 **Edge & Multimedia**: Zero-disk I/O architecture streaming directly to **AWS S3** delivered globally via **AWS CloudFront Edge CDN** (<15ms latency).
- 🧪 **Enterprise Reliability**: Hardened with an automated **35/35 E2E test suite (100% pass)** and zero-touch GitHub Actions CI/CD pipeline.

`Java 21` `Spring Boot 3.3` `Spring Cloud` `Apache Kafka` `Neo4j` `PostgreSQL` `Redis` `React 18` `AWS S3 / CloudFront` `Docker`
